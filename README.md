# Davide Albertazzi — Project Index

This is the profile repository and the source of the central GitHub Pages site:

**[Open the live project index](https://davidealbertazzi97-jpg.github.io/davidealbertazzi97-jpg/)**

An editorial index of my public work across agentic systems, educational software and local-first privacy tools.

## Public repositories

### Agentic systems

- [Open Upsilon Logic](https://github.com/davidealbertazzi97-jpg/OPEN-UPSILON-LOGIC) — logical memory vault and swarm orchestrator for autonomous agents.

### Education

- [Open Teacher Agent](https://github.com/davidealbertazzi97-jpg/OpenTeacherAgent) — agentic educational authoring in a single binary, with interactive exercises and standalone HTML export.
- [TeacherAgent.ex](https://github.com/davidealbertazzi97-jpg/TeacherAgent.ex) — experimental eXeLearning fork with AI-assisted interactive authoring.

### Privacy-first local AI

- [AI Privacy Studio](https://github.com/davidealbertazzi97-jpg/AI-PRIVACY-STUDIO-NO-GPU) — local document processing for OCR, transcription, redaction and conversion without GPU or cloud inference.
- [Photo Privacy Studio](https://github.com/davidealbertazzi97-jpg/photo-privacy-ai-cpu-only) — automatic and manual photo redaction with EXIF/GPS cleanup on CPU.
- [Video Privacy Studio](https://github.com/davidealbertazzi97-jpg/video-privacy-ai-no-gpu) — local face and license-plate anonymization with temporal tracking.
- [Audio Privacy Studio](https://github.com/davidealbertazzi97-jpg/audio-privacy-ai-cpu-only) — local transcription, PII review and selective beep/mute redaction.

### Accessibility and language

- [Local Reader](https://github.com/davidealbertazzi97-jpg/LOCAL-READER-NO-GPU) — inclusive OCR-to-speech reading on ordinary CPUs.
- [Offline AI Translation](https://github.com/davidealbertazzi97-jpg/offline-ai-translation-no-gpu) — local voice and document translation without a GPU.
- [Lite Dictation Daemon](https://github.com/davidealbertazzi97-jpg/LIGHT-DICTATION-DAEMON) — lightweight offline Italian dictation for Linux desktops.

The visual catalog in [`index.html`](./index.html) is intentionally dependency-free so it can be served directly by GitHub Pages.
