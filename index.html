Operating principles // signal

THE DESIGN CODE

Una linea comune attraversa repository diverse: costruire strumenti leggibili, utili e controllabili.

01

Local by default

Quando i dati sono sensibili, il primo confine di sicurezza è il dispositivo dell'utente: meno dipendenze, meno esposizione, più controllo.

02

Teaching first

La tecnologia deve arrivare fino a una persona reale: un docente, uno studente, un professionista, con un flusso comprensibile.

03

Ship the tool

Repository, installer, interfaccia e documentazione fanno parte dello stesso progetto: l'idea conta quando può essere usata.
